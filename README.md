# AI-Powered Cybersecurity Threat Detection System

A beginner-friendly defensive ML project that classifies **synthetic network telemetry** into normal, DoS-like, brute-force-like, and scan-like patterns. It includes dataset generation, preprocessing, a Random Forest model, evaluation metrics, a batch prediction pipeline, a local Flask API, and a small dashboard.

> **Safety & honesty note:** This project uses synthetic educational data only. It does not inspect live traffic, contact external systems, or prove that an actual host is compromised. Metrics are demonstrations on generated data, not production performance claims.

## Features
- Deterministic synthetic dataset generation (2,400 records by default)
- Reusable scikit-learn preprocessing and Random Forest pipeline
- Accuracy, macro precision, macro recall, macro F1, classification report, and confusion matrix
- Feature importance and batch predictions
- Local Flask dashboard and JSON prediction API
- Validation of required feature fields and non-negative numeric values
- Automated tests and architecture/security documentation

## Tech stack
Python 3.11 or 3.12 recommended, Pandas, NumPy, scikit-learn, Matplotlib, Joblib, Flask, Pytest, HTML/CSS/JavaScript. No GPU required.

## Architecture
See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md). The pipeline is: generate/read telemetry → validate and select features → impute/encode → train Random Forest → evaluate → predict/assign review level → display on local dashboard.

## Installation (Windows PowerShell)
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```
If activation is blocked, run `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` in that PowerShell session, then activate again.

## Run the project
Run these from the project root in order:
```powershell
python data\generate_dataset.py
python -m src.train_model
python -m src.run_detection
python -m src.app
```
Open `http://127.0.0.1:5000`. Leave the terminal running while you use the dashboard. Stop it with `Ctrl+C`.

### API example
`POST http://127.0.0.1:5000/api/predict` with JSON body:
```json
{
  "duration_seconds": 1.2, "src_bytes": 700, "dst_bytes": 400,
  "failed_logins": 15, "request_frequency": 60, "connection_count": 20,
  "packet_size": 500, "unique_ports_contacted": 2, "protocol": "TCP"
}
```
Also available: `GET /api/health`, `GET /api/summary`.

## Limitations and next improvements
Synthetic patterns can be easier to separate than real-world traffic. Next steps could include an approved public dataset, stronger leakage checks, cross-validation, calibration, drift analysis, explainability, and an analyst feedback loop. Any public dataset must be used according to its license and documented clearly.

## Portfolio description
Built an offline ML-based cybersecurity threat detection demo using Python, Pandas, scikit-learn, and Flask. Generated synthetic network telemetry, trained and evaluated a Random Forest classifier, and exposed predictions through a local dashboard and JSON API.
